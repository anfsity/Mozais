# Theme Package Contract

Mozais themes are ordinary Dart/Flutter packages. A theme package is the unit
that authors, tests, and builds a visual greeter experience. It does not import
another theme package.

## Package Shape

```text
packages/mozais_theme_<name>/
  pubspec.yaml
  assets/
  lib/
    <name>.scene.json
    <name>.scene.g.dart       # generated by build_runner
    theme.dart                # exports build<Name>Theme()
    components/
      ...                     # theme-owned Flutter widgets
  test/
```

The package depends on `mozais_theme_sdk` and `mozais_scene`. It may depend on
an explicitly shared component package such as `mozais_greeter_components`, but
it must not depend on `mozais_theme_default`, `mozais_theme_fallback`, or any
other concrete theme.

`theme.dart` creates one `ThemeDefinition` containing the generated
`SceneDocument`, its `ThemeBundle`, and its component factory. The scene's
`component` values are private to that theme's component factory. Assets are
declared by the package's `pubspec.yaml` and referenced with
`packages/<package>/assets/...`.

## Build Boundary

The scene generator discovers every `mozais_theme_*` package containing a
`.scene.json` file and runs `build_runner` in that package. Production code
consumes the generated Dart; it does not parse scene JSON at runtime.

An executable adds the theme package as a normal dependency and imports its
`build<Name>Theme` function from its own catalog. Flutter compiles that theme
code and assets into the executable. Runtime installation of new Dart/Flutter
theme code is outside this contract.
